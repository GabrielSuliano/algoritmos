# Algoritmos

Colecao de exercicios de logica de programacao desenvolvidos durante estudos de algoritmos. O arquivo principal reune exemplos de condicionais, operadores logicos, tomada de decisao e estruturas de repeticao.

## Conteudos praticados

- Entrada e saida de dados.
- Variaveis numericas e logicas.
- Condicionais `se`, `senao se` e `senao`.
- Regras de negocio simples.
- Validacao por idade, renda, notas e frequencia.
- Estruturas de repeticao com contadores.
- Soma, maior e menor valor.
- Tabuada.

## Arquivo principal

```text
algoritmos.lua
```

Apesar da extensao `.lua`, o conteudo esta escrito como pseudocodigo/Portugol usado em exercicios de logica.

## Como usar

Abra o arquivo em um editor de texto ou adapte os algoritmos para uma ferramenta de Portugol/Visualg conforme a disciplina.

## Status

Repositorio de estudos, usado para registrar progresso em logica de programacao.
